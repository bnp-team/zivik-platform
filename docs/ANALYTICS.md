# Аналітика НаСвітла: шпаргалка для менеджерів

На сайті два інструменти. Обидва без cookie й без банера згоди, тож нікого не
відстежують між візитами (див. «Файли cookie та аналітика» в політиці
конфіденційності).

| Що хочу знати | Де дивитися |
|---|---|
| Скільки людей читає, які сторінки, звідки приходять | **Cloudflare Web Analytics** |
| Куди на сторінці натискають і докуди прокручують | **PostHog → Heatmaps** |

## 1. Cloudflare Web Analytics: скільки й звідки

**Де:** dash.cloudflare.com → акаунт **botsDev** → **Analytics → Web
analytics** → сайт `nasvitlo.ucu.edu.ua`.
Доступ дає адміністратор botsDev: роль **Analytics** (лише перегляд).

| Показник | Що означає | На що дивитися |
|---|---|---|
| **Visits** | Скільки разів люди заходили на сайт | Динаміка місяць до місяця; стрибки після розсилок і публікацій |
| **Page views** | Скільки сторінок відкрили | Якщо переглядів набагато більше, ніж візитів, люди читають кілька справ поспіль |
| **Top pages / Paths** | Найпопулярніші сторінки | Які справи цікавлять найбільше; чи доходять до реєстру й мапи |
| **Referrers** | Звідки прийшли (Google, Facebook, сайт УКУ…) | Що реально приводить читачів |
| **Countries** | Країни читачів | Україна чи міжнародна аудиторія (для EN-версії) |
| **Devices / Browsers** | Телефон чи комп'ютер | Якщо більшість з телефонів, перевіряти справи й мапу саме на телефоні |
| **Core Web Vitals** | Швидкість завантаження | Зелене – добре; червоне – сказати розробникові |

**Чого ця статистика не скаже:** хто саме читав і чи повертається та сама
людина. Ми свідомо не збираємо таких даних.

## 2. PostHog: хітмапи

**Де:** eu.posthog.com → проєкт **НаСвітло** → **Heatmaps** → вставити адресу
сторінки, напр. `https://nasvitlo.ucu.edu.ua/uk/cases/icj-genocide`.
Доступ: власник проєкту запрошує в **Settings → Members**.

Як читати:
- **Кліки** – кольорові плями там, куди натискають. Червоне – часто, синє –
  рідко. Пляма на тексті чи картинці, які не є посиланням, означає, що люди
  чекають там посилання.
- **Прокрутка (Scroll depth)** – скільки відсотків читачів дійшли до кожного
  місця сторінки. Якщо до важливого розділу доходить менше половини, варто
  підняти його вище або додати посилання на нього вгорі.
- Дивіться окремо **комп'ютер і телефон**: поведінка зазвичай різна.

**Чого тут немає:** записів екрана (вимкнено свідомо), імен, пошт, IP. Хітмапи
складаються з багатьох візитів; одна-дві людини картини не дають. Чекайте
хоча б кількох десятків переглядів сторінки.

## 3. Що дивитися щомісяця (10 хвилин)

1. Cloudflare: **Visits** за місяць проти попереднього.
2. **Топ-5 сторінок**: які справи читають; чи є серед них нові.
3. **Referrers**: що спрацювало (розсилка, соцмережі, партнери).
4. PostHog: хітмапа **головної** і **найпопулярнішої справи**: куди
   натискають, докуди прокручують.
5. Висновок одним реченням – що змінити на сайті чи в розсилці.

## Технічне (для розробника)

- Cloudflare: ключ `NEXT_PUBLIC_CF_ANALYTICS_TOKEN`, PostHog:
  `NEXT_PUBLIC_POSTHOG_KEY` – змінні збірки Worker-а `nasvitlo`
  (Settings → Builds). Без значення відповідний скрипт не потрапляє на сайт.
- Код: `src/lib/analytics.ts`, `public/heatmaps.js`; текст політики –
  `src/content/legal.ts` (змінюється разом із налаштуваннями).
- Staging не рахується: там цих змінних немає.
