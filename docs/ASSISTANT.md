# Безпечний доступ для асистента (MCP)

EmDash має MCP-endpoint `/_emdash/api/mcp`: через нього ШІ-асистент може
читати й писати вміст так само, як редактор в адмінці.

## Що гарантує сайт

`site/emdash/review-policy.ts` блокує публікацію, зняття з публікації та
планування, коли запит прийшов з походженням `mcp`. Асистент пише **лише
чернетки**; публікує людина (роль Publisher і вище).

Обмеження: подія видалення не несе походження, тож видалення для MCP
заблокувати не можна. Воно йде в «Кошик» (остаточне видалення — окремий
інструмент), звідти запис відновлюється.

## Як підключити (робить власник; потрібен вхід в адмінку)

1. В адмінці створіть окремого користувача-«бота» з мінімальною роллю
   (Contributor / Author), а не власну обліковку.
2. Від його імені створіть персональний токен (Settings → API tokens) лише
   зі scope `content:read` і `content:write`. Без `admin`.
3. Токен вводьте лише в налаштуваннях клієнта асистента, ніколи в чат.
4. Адреса сервера: `https://nasvitlo.vm-55d.workers.dev/_emdash/api/mcp`
   (після запуску домену — `https://nasvitlo.org/_emdash/api/mcp`).
5. Після роботи токен відкличте або задайте йому короткий термін.

Усе, що зробив асистент, видно в «Ревізіях» запису; відкат — розділ 8
`docs/ADMIN-GUIDE.md`.
